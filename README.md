# ifcsis-site
Public website for ifcsis.org

## Pages
Each top-level section is its own page: `index.html` (home), `admission.html`, `standard.html`,
`about.html`, `faq.html`, `library.html`, `contact.html`. Old `/#/section` links redirect to them.
The library section produced by `build_library.py` goes into `library.html`.
